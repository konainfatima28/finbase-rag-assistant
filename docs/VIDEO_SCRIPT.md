# 5-minute video script (≤ 4:45 spoken)

Speaking pace ≈ 150 words/min. All numbers below come from the final evaluation run `20261007T014916Z-full` (`eval/results/latest.json`, `docs/EVAL_REPORT.md`).

| time | segment | on screen | say |
|---|---|---|---|
| 0:00–0:30 | **Problem** | Chat home page | "FinBase customers ask about loans, cards, UPI, FDs and KYC. The answer must come only from six official policy PDFs, with the exact source, and the assistant must say 'not in the knowledge base' instead of guessing. The PDFs are deliberately messy: corrupted rupee signs, glued pages, wrong section references in their own FAQs, contradictory values and truncated numbers." |
| 0:30–1:15 | **Architecture** | README Mermaid diagram | "Offline, a CLI cleans and parses the PDFs into a section tree, chunks by structure, de-duplicates, embeds with OpenAI text-embedding-3-small, and writes a FAISS plus BM25 index with a manifest. At runtime FastAPI redacts PII, rewrites follow-ups and non-English questions — including Romanised Hinglish — and splits broad questions into a few sub-queries. Hybrid retrieval is fused with Reciprocal Rank Fusion, reranked by an ONNX cross-encoder, assembled into a budgeted, de-duplicated context, and only then sent to gpt-4.1-mini. Code then verifies every citation and number and builds a canonical evidence list before streaming to the Next.js UI." |
| 1:15–1:50 | **Preprocessing + traps** | `docs/DATA_AUDIT.md` | "The audit runs on the PDFs themselves. The rupee sign is a ZapfDingbats glyph, so I map it by font. Page-break gluing made a naive parser see 86 FAQs instead of 100, so de-glue rules restore exactly 100. It also found two truncated amounts, six missing TOC sections, and four FAQ answers that cite the wrong section — including the foreclosure example in the brief, which says 4.2 when the rule is in 6.2." |
| 1:50–2:20 | **Chunking** | `python -m app.ingest.inspect --sample` | "One chunk per leaf section, tables as 'column: value' rows plus one fact chunk per row, one chunk per FAQ. Every chunk carries a contextual header with title, code, section and page. Templated boilerplate and the 100 repeated FAQs collapse from 1,172 chunks to 190. Without dedup, dense recall at 5 collapses from 0.94 to 0.30; fixed-size windows reach only 0.36 even with the full hybrid pipeline." |
| 2:20–2:45 | **Models** | `.env.example`, D-011/D-012 | "OpenAI for everything model-related, in development and production: text-embedding-3-small and gpt-4.1-mini, chosen because it honours temperature zero for reproducible evaluation. Retrieval stays local. The index manifest pins the embedder, and the API refuses to start if the configured model doesn't match." |
| 2:45–3:15 | **Retrieval** | `/eval` retrieval and ablation charts | "Dense and BM25 are fused with RRF, boilerplate is down-weighted, a router adds a soft boost but never filters, and FlashRank reranks. Conflicting sections found by the audit are always retrieved together. A calibrated gate abstains before the LLM when confidence is low. Hybrid plus rerank reaches recall at 5 of 0.98 and MRR 0.94, better than dense or BM25 alone." |
| 3:15–3:40 | **Prompt + hallucination control** | `prompts/answer_system.txt`, an answer with a source chip | "The prompt allows only numbered context blocks, requires a citation per sentence and a NOT_FOUND sentinel. Then code takes over: an uncited answer becomes a refusal, every figure is checked against the cited text, a truncated amount is never shown as a number, conflicts are detected in code with both values shown, and a fee asked for one product is never answered with another product's figure. Sources are de-duplicated into one numbered item per section." |
| 3:40–4:05 | **Evaluation** | `/eval` dashboard | "94 hand-verified golden questions across nine categories, including conflicts, absent information, Hinglish and attacks. Key-fact recall is 1.0, judged groundedness 0.98, citation precision 0.97, abstention F1 1.0 with zero over-refusal, and zero PII leaks. One injection item was flagged by the keyword detector even though the assistant refused it and gave the real 3% — I report that as measured rather than tuning the detector. The three retrieval misses are cross-document ranking cases where the answers are still correct. A question costs under a tenth of a cent; median latency is about 3.2 seconds after batching the reranker to fit Render's 512 MB." |
| 4:05–4:20 | **Trade-offs** | `docs/DECISIONS.md` | "Exact FAISS instead of a vector database because there are only 250 vectors; my own small orchestration instead of LangChain for control; safety decisions in code rather than trusting the model; and accuracy over latency for the reranker." |
| 4:20–4:45 | **Live demo** | Vercel app | Type the demo questions below; open the evidence drawer on the first answer. |
| 4:45–5:00 | **Improvements** | README last section | "Next: fix the cross-document ranking, make the injection detector robust to paraphrased refusals, and add a held-out evaluation set with a second judge model." |

## Demo questions (type exactly)

1. **Answerable + citation:** `What is the foreclosure charge if I close my personal loan after 18 months?` Click the inline citation `1` (or the source chip under the answer) → the evidence drawer opens with Section 6.2 and the cited line highlighted.
2. **Follow-up:** `What if I close it after 2 years instead?` (the follow-up is resolved from the conversation → 1.5%).
3. **Conflicting value:** `What is the mandate fee for personal loans?` Both ₹150 - ₹350 (Section 21) and ₹150 to ₹400 (Section 4.2) are shown with citations, plus a "Sources differ" note and Medium confidence.
4. **Not in KB:** `What is FinBase's home loan interest rate?` (the "Not in the knowledge base" card with the support contacts).
5. **Optional, if time allows:** `What is the contactless transaction limit for the savings account?` (an "Incomplete value in the source" note; the truncated daily limit is never shown as a number, Low confidence) or `Savings account kholne ke liye kya documents chahiye?` (Romanised Hinglish).
